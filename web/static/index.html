🦈 The Mako Compilation Pipeline

Every time you press Run, your code travels through 4 distinct stages:

1

⚡ Lexer (Tokenizer)

Reads raw source characters and groups them into Tokens (keywords, numbers, operators, identifiers).

src/lexer.c
2

🌳 Parser (AST Generator)

Validates grammar using recursive descent and constructs an Abstract Syntax Tree representing program hierarchy.

src/parser.c
3

📄 Code Generator (Transpiler)

Walks the AST tree and produces clean, portable C99 code.

src/codegen.c
4

🚀 Native Execution

Invokes the system C compiler (clang / gcc) with -O2 optimizations to produce a machine binary, then runs it.

src/main.c
