Compiler Architecture

Mako transforms source code into native machine code through a deterministic multi-stage pipeline.

01

Lexical Analysis

Partitions the UTF-8 input stream into typed tokens (identifiers, keywords, literals, operators).

src/lexer.c
02

Syntactic Analysis

Constructs a typed Abstract Syntax Tree (AST) validating grammatical correctness and statement hierarchy.

src/parser.c
03

Code Generation

Traverses the AST and emits portable C99 code with lexical scoping and runtime mappings.

src/codegen.c
04

Host Compilation

Invokes the system C compiler with -O2 optimization to produce and run a native binary.
